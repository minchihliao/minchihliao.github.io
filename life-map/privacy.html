適用對象

本應用程式僅供開發者本人與少數受邀者個人使用。

存取哪些 Google 資料

經使用者授權後，本應用程式只讀取與寫入使用者自己的 Google 日曆清單與行程，用來在人生地圖中顯示行程，並把使用者選定的行程同步到其 Google 日曆。不存取 Google 日曆以外的任何資料。

資料存放與分享

資料只存放在使用者自己的電腦，以及使用者自己的 GitHub 與 Cloudflare 帳戶中。不提供給任何第三方，不用於廣告，也不用於訓練任何模型。

本應用程式使用 Google API 取得的資料，遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

撤銷授權

使用者可隨時到 Google 帳戶的「第三方應用程式與服務」撤銷本應用程式的存取權。
